## Re-recording after the redesign

The script uses Playwright and a self-contained ffmpeg (Homebrew's ffmpeg on this Mac fails to load `libx265`). Selectors (`#seek`, `#play`, `#profile`, `#lang`, `#player`, `#speed`) may change with the redesign; update `tools/record.mjs` accordingly.

```sh
mkdir rec && cd rec && npm init -y && npm i playwright@1.56.1 ffmpeg-static@5.2.0
cp ../submission/video/tools/record.mjs . && mkdir vo && cp ../submission/video/tools/lines.txt vo/
# 1. voice-over: one file per line of lines.txt
i=1; while IFS= read -r l; do say -v Daniel -r 175 -o vo/s$i.aiff "$l"; node_modules/ffmpeg-static/ffmpeg -y -i vo/s$i.aiff -ar 44100 -ac 1 vo/s$i.wav; i=$((i+1)); done < vo/lines.txt
cp ../submission/video/tools/compose.py .
# 2. scene durations from the voice-over
python3 compose.py durations
# 3. record scenes (writes clips/scene<i>/frames.txt + JPEG frames)
node record.mjs
# 4. mux each scene with its voice-over and concatenate into draft.mp4
python3 compose.py mux
```

Alternatively, record the final cut by hand with a screen recorder and a human voice-over following `../video_script.md`.
